# Приложение для работы банковского сайта


## В приложении создан модуль views.py для приветсвия пользователя в зависимости от времени суток, и поиска информации по заданной дате в списке транзакций 
## В модуле views.py также реализован ответ в формате json, в котором содержится информация о курсе валют, стоимости акций и топе транзакций по сумме в указанном месяце
## В модуле services.py реализована возможность поиска транзакций по ключевому слову в категории или описании
## В модуле reports.py прописана функция, которая выдает суммы всех операций по определенной категории за три месяца до указанной даты


# Все встроенные модули интегрированы в файл main.py, который реализует обрабатывает файлы различных категорий и фильтрует содержащиеся в них транзакции по нескольким показателям и возвращает данные
